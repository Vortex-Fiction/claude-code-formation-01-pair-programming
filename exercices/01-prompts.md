# Exercice 1 — Réécrire trois prompts

**Objectif :** sentir la différence entre un prompt vague et un prompt en trois parties.

Rappel du modèle :

1. **Contexte** : où on est, ce qui existe, ce qui compte.
2. **Tâche** : ce que Claude doit faire, précisément.
3. **Format et contraintes** : ce qu'on attend en sortie, ce qu'il ne faut pas faire.

## Les trois prompts à réécrire

1. « Ajoute un champ. »
2. « Corrige le bug des emprunts. »
3. « Fais les tests. »

## Pour chacun

1. Écrivez la version en trois parties, pour **ce** repo.
2. Ouvrez une nouvelle session (`claude` à la racine du repo, ou `/clear`).
3. Envoyez d'abord le prompt vague, notez ce que Claude fait.
4. `/clear`, puis envoyez votre version réécrite.
5. Notez en deux lignes ce qui a changé dans la réponse.

Ne laissez pas Claude modifier le code pendant cet exercice : refusez les modifications ou lancez-le en mode plan (`Shift+Tab` jusqu'à « plan mode »).

## Réussi si

- Vos trois prompts nomment des fichiers, des routes ou des types du repo.
- Chaque prompt dit comment vérifier le résultat (un test, une commande).
- Vous pouvez expliquer pourquoi la deuxième réponse est meilleure.
